# Colab notebook

The working notebook was authored in Google Colab. To include it in this repository:

1. Open the RoadGuard_AI.ipynb notebook in Google Colab.
2. Choose File → Download → Download .ipynb.
3. Upload the downloaded notebook to this folder in GitHub, or use Git from a local clone.
4. Before publishing, remove any personal information, access tokens, API keys, and unnecessary output cells. Do not save dataset files or model weights into the notebook.

The main Python scripts in the repository (train.py, evaluate.py, and app.py) provide a reproducible code alternative to the notebook.
